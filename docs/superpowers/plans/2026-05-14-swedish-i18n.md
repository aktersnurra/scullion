# Swedish i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Translate all Scullion UI strings to Swedish using Phoenix gettext with the locale stored on the user record and set per-request.

**Architecture:** Add a `locale` field to the `users` table (default `"sv"`), create a `ScullionWeb.Plugs.Locale` plug that sets the gettext locale from the current user on every request, and also set it in the existing `ScullionWeb.Live.Auth` `on_mount`. Wrap all hardcoded UI strings in `gettext()`, extract to `.pot`, generate `sv` `.po` files, and fill in Swedish translations.

**Tech Stack:** Elixir/Phoenix, Ecto, Phoenix LiveView, `gettext` (already configured via `ScullionWeb.Gettext`), `mix gettext.extract`, `mix gettext.merge`

- [ ] **Step 3: Write the plug**

```elixir
# lib/scullion_web/plugs/locale.ex
defmodule ScullionWeb.Plugs.Locale do
  import Plug.Conn

  @behaviour Plug

  @impl Plug
  def init(opts), do: opts

  @impl Plug
  def call(conn, _opts) do
    locale =
      case conn.assigns[:current_user] do
        %{locale: locale} when is_binary(locale) -> locale
        _ -> "sv"
      end

    Gettext.put_locale(ScullionWeb.Gettext, locale)
    conn
  end
end
```

- [ ] **Step 2: Set locale in LiveView on_mount**

In `lib/scullion_web/live/auth.ex`, update `mount_current_user/2` to also set the locale after assigning the user. Add at the top: `alias ScullionWeb.Gettext, as: GettextBackend`.

```elixir
defmodule ScullionWeb.Live.Auth do
  import Phoenix.LiveView
  import Phoenix.Component, only: [assign: 3]
  alias Scullion.Accounts

  def on_mount(:require_authenticated, _params, session, socket) do
    socket = socket |> mount_current_user(session) |> attach_current_path()

    if socket.assigns.current_user do
      {:cont, socket}
    else
      {:halt, redirect(socket, to: "/login")}
    end
  end

  def on_mount(:require_admin, _params, session, socket) do
    socket = socket |> mount_current_user(session) |> attach_current_path()

    case socket.assigns.current_user do
      %{role: :admin} -> {:cont, socket}
      nil -> {:halt, redirect(socket, to: "/login")}
      _ -> {:halt, redirect(socket, to: "/")}
    end
  end

  defp attach_current_path(socket) do
    socket
    |> assign(:current_path, "/")
    |> attach_hook(:current_path, :handle_params, fn _params, url, socket ->
      path = URI.parse(url).path || "/"
      {:cont, assign(socket, :current_path, path)}
    end)
  end

  defp mount_current_user(socket, session) do
    case session["user_id"] do
      nil ->
        Gettext.put_locale(ScullionWeb.Gettext, "sv")
        assign(socket, :current_user, nil)

      user_id ->
        user = Accounts.get_user!(user_id)
        Gettext.put_locale(ScullionWeb.Gettext, user.locale || "sv")
        assign(socket, :current_user, user)
    end
  rescue
    Ecto.NoResultsError ->
      Gettext.put_locale(ScullionWeb.Gettext, "sv")
      assign(socket, :current_user, nil)
  end
end
```

- [ ] **Step 1: Wrap strings in each live view**

For each file, find all user-visible strings hardcoded in the `~H` template sections and in `put_flash/3` calls. Wrap them with `gettext("...")`.

**What to wrap:**
- Page headings, labels, button text, placeholder text, empty state messages, flash messages, error strings assigned to `socket`

**What NOT to wrap:**
- Event names (`"search"`, `"filter_tag"`, etc.)
- CSS class strings
- URL paths
- Field/key names used in pattern matching
- Day abbreviations used as data keys (`"mon"`, `"tue"`, etc.)
- `aria-label` values that are purely for screen readers can be wrapped too for completeness

**Example — before:**
```elixir
{:noreply, put_flash(socket, :info, "Coming soon")}
```

**Example — after:**
```elixir
{:noreply, put_flash(socket, :info, gettext("Coming soon"))}
```

**Example — template before:**
```heex
<h1>Groceries</h1>
<.empty message="No items yet" />
<input placeholder="Add item…" />
```

**Example — template after:**
```heex
<h1><%= gettext("Groceries") %></h1>
<.empty message={gettext("No items yet")} />
<input placeholder={gettext("Add item…")} />
```
