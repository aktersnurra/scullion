# Demotion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land three housekeeping tracks in one plan: (a) rename `Tore.Family.*` → `Tore.Household.*` with DB table renames, (b) demote `/pantry` and `/costs` out of main nav and into `/settings/*`, stripping pantry_live.ex from 445 lines of full CRUD to ~80 lines of read-only-plus-remove, (c) delete the `Tore.Jobs.HomeNote` stub job and the `CounterNotes.build_home_note/1` placeholder string.

**Architecture:** Three sequenced sections, three commits, no overlap. §1 is one atomic commit (migration + module + call-site rename — partial rename = broken build). §2 lands route + nav + pantry strip + costs move + settings links in one commit (atomic UI surface change). §3 is a small deletion commit. After each section: `mix test` runs to the same pre-existing failure floor (5–7 in `Groceries*` and a SQLite race in the renamed `HouseholdTest`); anything new is a regression.

**Tech Stack:** Elixir/Phoenix/LiveView, Ecto + SQLite, Quantum scheduler, jj for VCS.

**Spec:** `docs/superpowers/specs/2026-05-31-demotion-design.md`. The plan implements every numbered success criterion.

**VCS:** Use `jj describe -m "..."` + `jj new`. Never `git commit`. Before starting any task, run `jj st` and confirm an empty working copy (the controller sets that up for you).

```elixir
defmodule Tore.Household.HouseholdSchema do
  use Ecto.Schema
  import Ecto.Changeset

  schema "households" do
    field :name, :string
    field :locale, :string, default: "sv"
    has_many :users, Tore.Accounts.User, foreign_key: :household_id
    has_one :preferences, Tore.Household.Preferences, foreign_key: :household_id
    timestamps()
  end

  def changeset(household, attrs) do
    household
    |> cast(attrs, [:name, :locale])
    |> validate_required([:name, :locale])
    |> validate_length(:name, min: 1, max: 100)
    |> validate_inclusion(:locale, ~w(sv en))
  end
end
```

- [ ] **Step 1.2.2: Create `lib/tore/household/household_insight.ex`**

```elixir
defmodule Tore.Household.HouseholdInsight do
  use Ecto.Schema
  import Ecto.Changeset

  schema "household_insights" do
    field :kind, :string
    field :body, :string
    field :confidence, :float, default: 0.5
    field :evidence, :string
    field :status, :string, default: "active"
    field :generated_at, :utc_datetime
    timestamps(updated_at: false)
  end

  @valid_statuses ~w[active superseded dismissed]
  @valid_kinds ~w[skip_pattern cascade_success time_preference cuisine_fatigue variety_win]

  def changeset(insight, attrs) do
    insight
    |> cast(attrs, [:kind, :body, :confidence, :evidence, :status, :generated_at])
    |> validate_required([:kind, :body, :confidence, :generated_at])
    |> validate_inclusion(:status, @valid_statuses)
    |> validate_inclusion(:kind, @valid_kinds)
    |> validate_number(:confidence, greater_than_or_equal_to: 0.0, less_than_or_equal_to: 1.0)
  end
end
```
